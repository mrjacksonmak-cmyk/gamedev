Les 3 ingrédients magiques

Comme une recette de gâteau, un jeu a besoin de 3 choses :

L'HTML

C'est le squelette. On place les objets (boutons, écran).

Le CSS

C'est le costume. On choisit les couleurs et les formes.

Le JavaScript

C'est le cerveau. Il décide comment on bouge et gagne.

HTML : On dessine la carte

Le code HTML dit : "Je veux un écran pour dessiner (Canvas) et un compteur de pièces."

<!-- L'écran de jeu -->
<canvas id="gameCanvas"></canvas>

<!-- Le compteur de pièces -->
<span id="coin-count">0</span>

CSS : On décore !

Sans CSS, le jeu serait tout triste et blanc. Le code CSS donne de la couleur au ciel et place les boutons.

#game-container {
  /* Ciel bleu dégradé */
  background: linear-gradient(to bottom, #87CEEB, #E0F6FF);
}

La mémoire du jeu

Le JavaScript utilise des Variables. C'est comme des boîtes où l'on range des informations qui changent.

let coinsCollected = 0; // On commence à zéro
let currentGravity = 0.6; // La force qui nous fait tomber

Quand tu attrapes une pièce, on ouvre la boîte et on fait +1 !

Comment naît Monsieur Stick ?

Le personnage "옷" n'est pas une image, il est dessiné par le code avec des lignes et des ronds, 60 fois par seconde !

// Dessiner la tête (un rond)
ctx.arc(px, py - 15, 8, 0, Math.PI*2);

// Dessiner le corps (une ligne)
ctx.lineTo(px, py + 10);

La Magie de la Science

0.6

C'est le chiffre magique de la gravité.

Pourquoi on tombe ?

Dans le code, on dit au personnage : "À chaque instant, ta vitesse vers le bas augmente un petit peu."

player.vy += currentGravity; // On tire vers le bas
player.y += player.vy; // On déplace le héros

Si tu changes 0.6 par 0.1, tu voleras comme sur la Lune !

Le cœur qui bat (La Boucle)

Un jeu ne s'arrête jamais de réfléchir. Il fait ce cycle 60 fois par seconde :

1. Écouter

Tu appuies sur une touche ?

2. Calculer

Changer la position du héros.

3. Vérifier

On a touché une boule de feu ?

4. Dessiner

Afficher la nouvelle image.
